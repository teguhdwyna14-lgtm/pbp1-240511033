Bagian 2 – Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, PHP | Java, C#, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-Server | Standalone atau Client-Server | Mobile Client-Server |
| Cara distribusi | Melalui URL/browser | Instalasi aplikasi pada komputer | Play Store, App Store, atau APK |
| Keunggulan | Multiplatform, mudah diakses, tidak perlu instalasi | Performa tinggi, akses hardware lebih luas, dapat berjalan offline | Portabel, praktis, mendukung GPS dan kamera |
| Keterbatasan | Umumnya membutuhkan internet, bergantung pada browser | Bergantung pada sistem operasi, membutuhkan instalasi | Layar kecil, baterai dan sumber daya terbatas |
| Contoh aplikasi | Google Docs, Gmail, YouTube Web | Microsoft Word, Adobe Photoshop, VLC | WhatsApp, Gojek, Instagram |
